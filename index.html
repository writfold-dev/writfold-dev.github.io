Git-native project continuity for coding agents

Deterministic agent work
that resumes where it stopped.

Writfold keeps an agent’s plan, checks and decisions as plain records in Git.

Deterministic

Citations pinned to a commit. Gates with receipts tied to the exact bytes they checked. A plan the agent walks, and guard rules that hold a command until its gates are met.

Resumable

A new session on any machine reads a brief and the last checkpoint. It does not reload the whole project to pick the work up.

Deterministic

A plan the agent walks, checked against exact bytes

A run has a plan, and each step owes gates: small checks that leave a receipt. writfold watch draws it in your terminal.

✓ Done, and still true
A step is recorded as done only when every gate it owes is met.
! Done, but something moved
A later edit changed the bytes a gate checked. The step stays done and is flagged.
▶ Next
The step to pick up, from the record. It is not a claim that an agent is working.

Gates block nothing on their own; a guard rule you add can deny a command such as git commit until they are met. The view is read-only.

Resumable

A new session reads a brief, not the project

Three verbs carry work across sessions. Then the agent asks why, status, tracker and impact questions, and every line of an answer names its source.

kb brief
Where the project stands. The Claude Code plugin adds it at session start.
kb resume
Where the run stopped: its last checkpoints, plan position and owed gates.
kb checkpoint
A note written into the run for the next session.

No server

Plain records in Git, and one binary

Git is the source of truth

Decisions, tickets, runs and receipts are Markdown and JSON files. Writes are left uncommitted for you to review.

The index is derived

A local SQLite file, rebuilt from Git whenever needed. A new machine needs git clone and the binary.

It records and reports

Your agent keeps its own loop and model. Writfold schedules nothing.

Try it

Download, verify, install the plugin

Linux x86_64 or WSL2.

base=https://github.com/writfold-dev/writfold/releases/download/v0.5.0-dev.9
curl -LO "$base/writfold-x86_64-linux-musl" -LO "$base/writfold-x86_64-linux-musl.sha256"
echo "$(cut -d' ' -f1 writfold-x86_64-linux-musl.sha256)  writfold-x86_64-linux-musl" | sha256sum -c
install -m 755 writfold-x86_64-linux-musl ~/.local/bin/writfold

claude plugin marketplace add writfold-dev/writfold
claude plugin install writfold@writfold

Single user, cooperating agents, local clones only; nothing is fetched. Setup is in the README.

Pre-release: formats and verbs may still change. What runs today, what is planned, and what is proved and tested.
