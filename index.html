Git-native project continuity for coding agents

Project memory in Git
that says when it is stale.

Every new agent session starts without the project’s history. With Writfold, a fresh session on any machine can answer four questions, and each answer names the file and commit it came from.

  • Why did we decide X?
  • Where do we stand on Y?
  • What is the tracker item for Z?
  • What does changing X touch?

The flow

Research, plan, execute, deliver. Each stage writes back.

The agent keeps its own loop and model. What it finds, checks or drafts at each stage goes back into the knowledge base, so the next session starts from more than this one did.

The knowledge base is plain Markdown and JSON in Git. Writes are left uncommitted for you to review and commit. The index refreshes itself on every read; kb check re-checks citations, the index, gate evidence and the plan on demand. Walk through the stages.

Inside a run

Steps, gates, and what is still owed

A plan is an ordered list of steps, each naming the gates it owes. A gate is one small check: a command and the paths it covers, a statement someone must make, or a check of the run’s own records. gate run keeps a receipt for the exact bytes checked, and plan advance records a step as done only when every gate is met.

Writfold records the plan and the agent walks it. Gates and steps report; a guard rule you add can hold a command until they are met.

Try it

Download, verify, install the plugin

Linux x86_64 or WSL2. The plugin adds a project brief, the plan position and an inbox at session start, and keeps local checkpoint drafts.

base=https://github.com/writfold-dev/writfold/releases/download/v0.5.0-dev.2
curl -LO "$base/writfold-x86_64-linux-musl" -LO "$base/writfold-x86_64-linux-musl.sha256"
echo "$(cut -d' ' -f1 writfold-x86_64-linux-musl.sha256)  writfold-x86_64-linux-musl" | sha256sum -c
install -m 755 writfold-x86_64-linux-musl ~/.local/bin/writfold

claude plugin marketplace add writfold-dev/writfold
claude plugin install writfold@writfold

Single user, cooperating agents, local clones only; nothing is fetched. Setup is in the README.
