Git-native project continuity for coding agents

Project memory in Git
that says when it is stale.

Every new agent session starts without the project’s history. Writfold is being built so that a fresh session, on any machine, can answer four questions, and each answer names the file and commit it came from.

  • Why did we decide X?
  • Where do we stand on Y?
  • What is the tracker item for Z?
  • What does changing X touch?

How it works · planned

Records in Git, an index you can rebuild, answers you can check

Agent memory features live with one tool, on one machine or account. Notes in Markdown travel, but nothing tells you when the code they describe has changed. Writfold is planned to do both: records that live in Git and are reviewed, merged and cloned like code, and answers that say when their source has moved. The agent keeps its own loop and model, and asks Writfold about the project.

01

Records in Git

The knowledge base will be plain Markdown and JSON records in a Git repository. Git is the only store, so a new machine needs git clone plus the binary.

02

A rebuildable index

A local SQLite index will be derived from those records and kept in sync by Writfold itself, so it can always be rebuilt. It will include fuzzy (typo-tolerant) text search.

03

Pinned, flagged when stale

Each answer will name its source: a path at a commit, with a digest of the bytes read. When that source has moved since, the answer will say so.

Planned as one static binary, with no server and no database to run.

Planned first

The first slice

Four read-only commands over a knowledge base of plain Markdown and JSON records in a Git repository. Each answers one question:

brief
Where do we stand?
why
Why did we decide X?
context
What is around this one thing?
stale
Which sources have moved?

The tracker and impact questions come after, with the index and fuzzy search, then writes and checkpoints, then a Claude Code plugin and MCP. Status and roadmap.

Earlier work still builds and runs from source as frozen demos: the edit trial, Weft, Splicery and Tuft. See earlier work.
