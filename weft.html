01 / A small, explicit theory

A plan is not a successful restore.

This example assumes that the payments service has a plan. It asks whether that same fact follows, and whether a successful restore follows too. No rule connects the two.

Download review.weft · exact source used for this assessment

review recovery_plan {
  context "unresolved-sandbox" at "unresolved-release";
  profile "weft.symbolic/1";
  target change = proposal "unresolved-plan";

  assume documented: has_plan("payments");
  check docs_only: has_plan("payments");
  check restore_works: restores("payments");
}

An assumption is an input, not evidence.

assume documented puts has_plan("payments") into the theory. The label does not mean Weft read a runbook or verified a service. Each check asks what follows from that declared theory.

Deliberately unresolved

Names do not establish grounding.

The context, release and proposal strings are intentionally unresolved. They do not identify a verified Writfold context, retained release or authorized change. This example is hypothetical, not a query against a live knowledge store.

02 / Actual assessment

Complete does not mean all proved.

The following command was exercised with the pinned development binary, using the downloaded file. It is not an installation quickstart or a promise that Weft is already available on your system.

weft prove review.weft --json

docs_only · entailed

The assumption supports this check.

has_plan("payments") follows because it was explicitly assumed. The result is conditional on the declared theory, not independent confirmation that a plan exists.

restore_works · undetermined

The theory does not settle this check.

Neither restores("payments") nor its negation follows. Undetermined is not refuted: the example establishes neither a successful restore nor a failed one.

The report records basis=hypothetical, execution=complete, writfold_grounded=false and effect_authority=false. These are result fields, not an abbreviated JSON transcript.

Complete hypothetical assessments exit 1—even when every check is entailed. Here, one check remains undetermined. Read the result categories; neither completion nor entailment grants permission to edit anything.

03 / The assessment boundary

Follow the source, not a fictional proof.

A bounded logical claim.

Weft evaluates the declared finite theory. It does not prove an arbitrary implementation correct, extract all facts from prose, or demonstrate that a production restore works.

Evidence and authority remain separate.

A source-bound report is not automatically Writfold-grounded evidence. Owner-backed context resolution and authorization are separate boundaries; the complete Writfold owner data and effect services remain unavailable.
